# Rod & Cement Shop Management System

A complete shop management web application built with Raw PHP + MySQL.

## Tech Stack
- **Backend:** Raw PHP (OOP, No Framework)
- **Database:** MySQL (PDO)
- **Frontend:** Bootstrap 5, JavaScript, AJAX
- **Charts:** Chart.js
- **PDF:** FPDF Library

## Project Structure
```
/
├── config/          # Database config
├── classes/         # PHP OOP Classes
├── includes/        # Reusable HTML parts
├── pages/           # Page files
├── api/             # AJAX API endpoints
├── assets/          # CSS, JS, Images
├── pdf/             # PDF generation
└── index.php        # Login page
```

## Phases
- **Phase 1:** Foundation (Database + Login + Navigation)
- **Phase 2:** Product Management (Rod + Cement)
- **Phase 3:** Stock Management
- **Phase 4:** Sales System
- **Phase 5:** Payment / Khata (Credit)
- **Phase 6:** Reports & Dashboard
- **Phase 7:** Users, Suppliers, Settings
